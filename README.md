# Comfy Loot

Cozy drop tracker

## Main Points

- Simple UI
- Keep track of lootdrops
- Calculate marketboard value (not yet implemented)

## How To Use

Upon install Comfyloot keeps track of every item you aquire over this play session.
`/loot` opens a simple but handy overview.
